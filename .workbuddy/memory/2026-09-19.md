## 网站图标设计（同日）

原图标是靛蓝方块 + 一个「W」形折线，读不出「库」的含义。重做为「云 + 收纳盒」：
云朵压在开口托盘上方，配站点既有的靛蓝→青渐变。

**形状构造要点（易踩坑）**
- 云朵一开始用「3 个圆 + 圆角矩形」拼接，圆形与矩形圆角处会出现肉眼可见的凹口。
  原因是矩形的圆角圆心到圆的距离 + 圆角半径 > 圆的半径，圆角露在了圆外。
- 正确做法：让矩形的左右边缘**正好落在左右两个圆的圆心 x 上**（矩形 rx 设 0），
  这样矩形角点就在圆心上，一定被圆包住；且圆与底边相切，底边自然过渡，无接缝。
  最终云形 = 4 个图元（3 圆 + 1 直角矩形），底边 x∈[11.7, 20.7] 平直。

**方案对比**（三版都渲染成 PNG 实际看过）
- A 云台：云 + 一条横杠 → 干净，但横杠像游离的短横，语义弱
- B 云归档：云 + 下箭头 → 动作感强，但箭头偏细、易读成字母 V
- C 收录盒：云 + 开口托盘 → **选定**，语义最足且小尺寸仍可辨

**产出文件**
- `public/favicon.svg` —— 主图标（矢量，浏览器首选）
- `public/apple-touch-icon.png` / `favicon-32.png` / `favicon.ico` —— 位图兜底
- `design/favicon-a|b|c.svg` + `design/preview/*.png` —— 备选方案与对比图
- `tools/make-icons.mjs` —— SVG → PNG/ICO 光栅化（含手写 ICO 封装）
- index.html 的顶栏 brand-mark 与启动页 boot-mark 换成同一 glyph（fill/stroke 用 currentColor）

**新增工具链**
`@resvg/resvg-js` 装在托管 Node 工作区（`C:/Users/chenq/.workbuddy/binaries/node/workspace`），
项目里用 `createRequire('<workspace>/noop.js')` 解析，**不往项目 node_modules 里装**（否则会被一起部署）。

## 推送代码到 GitHub（同日）

**目标**：把项目推到 https://github.com/yulechen/tranding-news（远端原本是空仓库，PUBLIC）。

**做法**
- 本机 `gh` 已登录 `yulechen`（token 含 `repo` scope），先 `gh auth setup-git` 挂好凭据助手
- 身份只设 **repo 局部**（`user.name=yulechen`，
  `user.email=3973126+yulechen@users.noreply.github.com`），**不动全局 git 配置**
- `core.autocrlf` 全局是 `true`，本仓库局部改为 `false`（源文件都是 LF，避免工作区被转成 CRLF 后
  每次 touch 都报 modified）
- 首次提交 26 个文件、`main` 分支：`git init -b main` → `add` → `commit` → `remote add origin` → `push -u`

**踩坑记录**
- `.gitignore` 里把临时文件规则写成 `.tmp-*/`（带尾斜杠只匹配**目录**），
  结果 `.tmp-commit-msg.txt` 被 `git add -A` 一并提交。改成 `.tmp-*` 后已从提交中剔除。
  验证忽略规则要用 `git check-ignore -v --no-index <path>` —— 不加 `--no-index` 时，
  已被跟踪的文件一律报「未忽略」，容易误判规则没生效。
- **`git fetch` 报「[new branch] main -> origin/main」，但 `refs/remotes/origin/main` 实际没落盘**
  （`for-each-ref refs/remotes` 为空、`status -sb` 显示 `[gone]`、`rev-parse origin/main` 解析失败）。
  这是沙箱对 `.git` 写入的隔离所致，不是 git 或远端的问题。判据是 `git ls-remote origin`
  仍返回正确的 sha。**解法**：用 node 直接 `mkdir -p .git/refs/remotes/origin` 再写入 sha 文件，
  之后 `status -sb` 即恢复为 `## main...origin/main`。
