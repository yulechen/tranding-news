云端信息库

你的内容，收在一个地方

在微信里让 WorkBuddy 生成的 HTML，全部归档到这里统一查看。

内容是怎么进来的

1
你在微信里发指令比如「做一份美股盘前快报」，WorkBuddy 在本地生成一个 HTML 文件。
2
自动推进云端信息库内容连同标题、摘要、标签一起写入云端，不需要你手动传。
3
打开链接就能看列表按时间倒序。点卡片默认在新窗口打开，也能页内预览或下载。

页面上能做什么

操作说明
标签每张卡片右上角点一下就能打标签，顶部按标签筛选 —— 标签由你自己维护
收藏工具条第一个「收藏」只看收藏；卡片星标或预览页按钮随时加 / 取消
类型筛选报告 / 看板 / 工具 / 页面 / 其他，工具条一排小标签切换
打开内容点卡片默认在新窗口打开，整页看，不受页面宽度限制
页内预览卡片右上角第一个按钮（眼睛），在当前页不出门就能扫一眼
编辑信息改标题、摘要、标签、类型（预览页里）
接口 / 留言顶栏可查推送接口文档，也能留一句话
排序固定按时间倒序，最新的在最前面，收藏的置顶

命令行推送

# 直接入库，内容立刻出现在页面上（推送不写标签，标签在页面上手工维护）
node tools/push.mjs --file 快报.html --title "美股盘前快报"

# 先暂存到收件箱，之后在页面上点「全部归档」
node tools/push.mjs --file 快报.html --title "美股盘前快报" --inbox

# 从标准输入读，适合管道串联
cat 快报.html | node tools/push.mjs --stdin --title "美股盘前快报"

几个小知识

● 公开可看没有登录，任何人打开链接都能浏览里面的内容。
● 单条上限 2MB超了会拒绝，太大的页面建议拆开或压缩内嵌资源。
● 列表不拉正文首页只取标题和元信息，点开才按需加载内容，所以列表很快。
● 页内预览是隔离的在独立环境里渲染，里面的脚本碰不到管理系统本身。
● 标签自己维护推送不会自动打标签，免得词越堆越乱；在卡片上手工打，顶部按标签筛。
